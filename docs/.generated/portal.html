BIYA DEX API 网关聚合文档

前端唯一入口：POST /info、POST /exchange、GET /ws 均打网关，由网关按 type / 订阅分流到三后端，网关不改业务字段、不回退。左侧选接口，右侧看说明、改参数、直接发送。

共 22 个 POST 接口、19 个 WS 订阅。

测试指南

  • 每个 POST 接口自带填好参数的测试用例，改完点发送，结果原样展示（含业务错误体）。
  • 每个 WS 订阅自带订阅报文，点连接即收消息；断开会显示 close code。
  • 右上可切换服务器（公网 / 139 本机）。浏览器无痕模式同样可用，无需登录。
Exchange · POST /exchange

POST /exchange · 提交签名动作 经网关走 交易池。

提交已签名的 exchange action；accepted 仅表示通过本地校验进入交易池，不代表链上执行。

入参

参数类型说明
action *object9 种动作 oneOf（order/cancel/cancelByCloid/cancelAll/updateLeverage/batchModify/usdSend/withdraw3/approveAgent），。各动作字段见下表与片段说明。
nonce *integer用户 nonce，必须大于 0。
signature *object{r, s, v}；r/s 32 字节 hex，v 为 27/28。
vaultAddressstring可选，20 字节 hex。
expiresAfterinteger可选，参与签名。

响应

状态码含义
200本地处理结果：code 0=已入池；1001 参数/哈希失败；1002 重复交易；1003 签名失败。
400malformed JSON，Axum 在进业务逻辑前拒绝。

Exchange__ExchangeResult

{
  "code": 0,
  "message": "accepted",
  "tx_hash": ""
}
